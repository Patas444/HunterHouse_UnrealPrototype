# HunterHouse_UnrealPrototype
Este es mi prototipo de un juego de terror inspirado en un mapa antiguo realizado en Minecraft con un viejo amigo. En este juego relata la aventura de 2 investigadores que exploran una mansión aparentemente abandonada donde se suelen realizar fiestas, sin embargo siempre reportan desapariciones o incluso muertes en ella pero nunca se ha confirmado hasta ahora. Durante la investigación nuestros protagonistas se dan cuenta que no están solos y probablemente se encuentran con el perpetrador de las desapariciones. Tu misión es escapar de esa mansión antes de que te conviertas en la presa de este cazador.
